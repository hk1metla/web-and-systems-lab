# Alphabetic Cipher Demonstration

Small C++ programs demonstrate repeating-key modular encryption and decryption over uppercase letters.

```bash
g++ -std=c++17 encrpt1.cpp -o encrypt
./encrypt
g++ -std=c++17 decrypt1.cpp -o decrypt
./decrypt
```

The source includes an explicit example phrase/key. They are demonstration constants, not credentials. These classical algorithms are unsuitable for protecting confidential information. The decryptor includes its own example and is not an interoperable file format.
